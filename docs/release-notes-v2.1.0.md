# XimoAgent v2.1.0 更新说明

> 发布日期：2026-09-25 ｜ 版本跨度：v1.0.9 → **v2.1.0**（v2 为架构级重写：Go 高并发引擎 + Electron 桌面端）

## 一、本次更新概述

本版本一次性落地 5 个并行开发的功能模块（输入框模型切换与 GO 模式、流式诊断与权限面板、专家弹窗选择器、可视化计划模式、多代理并行与模型池），并完成 15 项合并审核修复（含用户实测反馈的保存回退、获取模型失败、流式体验等问题）。全部改动通过后端 `build.cmd verify`（build + vet + 全量短测）与前端双 tsconfig typecheck 验证，关键路径有专项回归测试锁定。

## 二、新增功能

### 1. 输入框模型切换
输入框旁新增「本次模型」选择器，展开即拉取当前服务商的模型列表；不选择时自动跟随设置页全局默认。

### 2. GO 模式
一键"直接执行"：减少低风险步骤上的反复确认。与计划模式互为反向开关。

### 3. 流式输出
主对话轮次全程 SSE 流式，模型增量实时推送到界面打字机渲染；长任务收尾总结轮同样流式。内置双端诊断开关（后端 `XIMO_STREAM_DEBUG=1`、前端 `localStorage.setItem('ximo.debug.stream','1')`）。

### 4. 权限模式面板
设置页可视化切换 5 档权限：yolo / safe / coding / office / design。写入 config.json，重启应用后生效。

### 5. 专家弹窗选择器
输入框左侧入口或输入 `/expert` 呼出：自动推荐 + 候选键盘快选 + 全库搜索。选中后本次消息直接绑定该专家，直连专家两阶段编排（先方案后执行）。5 套主题全适配。

### 6. 可视化计划模式
打开「计划」开关提交：模型先产出执行计划，聊天流内出现计划确认卡片（含步骤拆解）。确认 → 按批准的计划执行；拒绝 → 重新规划。计划与决定全部落持久日志，引擎重启后仍可确认执行。

### 7. 子代理并行执行 + 资源闸门
专家子代理并行执行，`expert_agent` 独立资源类硬上限 **并发 ≤ 8**，与普通工具槽位隔离；子代理工具调用走引擎统一派发链路，不绕过限流。

### 8. 多服务商模型池 + 失败转移
主服务商 + 多候选候选池；某候选持续 429/断线时自动切换下一个健康候选，同一任务无缝续跑。支持按专家/分类维度指定候选顺序；候选轮询一遍即止不死循环。

### 9. 设置面板增强
新增「子代理模型分配」面板：候选池可视化管理（增删/排序/编辑）+ 全局候选顺序 + 按专家分类覆盖。**自动获取候选**：一键向主服务商拉取模型列表，勾选后批量生成候选，无需手动复制粘贴。

### 10. 出网代理支持
对服务商的所有请求按「环境变量代理 → Windows 系统代理 → 直连」顺序解析，回环地址始终直连。国内无法直连的服务商在开启系统代理后即可正常使用。

## 三、问题修复

1. **保存配置被回退**：修复候选池旧快照覆盖用户刚填的地址/模型/密钥引用的问题。
2. **获取模型失败**：修复后端不走系统代理导致的直连超时；获取模型现使用表单当前地址（无需先保存）。
3. **坏地址静默保存**：接口地址统一规整（自动补 `https://`、去尾斜杠），不合法给出明确错误。
4. **引擎重启后确认计划丢失**：恢复路径补齐计划模式标记，已批准的计划在重启后仍会真正执行。
5. **专家阶段事件不可见**：阶段跃迁改为持久事件，断线重连后阶段状态不再丢失。
6. **流式去重对齐**：合并帧 Seq=0 语义前后端对齐，流式不丢帧。
7. **事件长轮询积压**：dwell 上界小批快返，历史重放不再长时间攒批。
8. **配置兼容**：老版单 provider 配置无痛加载；未使用新功能时保存不产生多余键。
9. **空池/全熔断防御**：候选全排除时给出「最不坏」兜底而非罢工；轮询上限防死循环。
10. **空会话场景按钮绕过计划开关**：输入框选项（计划/GO/模型/专家）提升至全局状态，场景按钮与手动发送走同一套规则。
11. **密钥安全**：引用写入失败不静默；错误信息统一脱敏。

## 五、安装与更新

### 全新安装
1. 下载 `XimoAgent-Setup-2.1.0.exe`，双击安装（可选安装目录）。
2. 启动后在 设置 → 模型与 API 凭据 中填入第三方 OpenAI 兼容接口地址与 API 密钥。
3. 点「获取模型」选择模型（国内不可直达的地址请先开启系统代理，后端会自动走系统代理），保存。

### 已安装旧版本
- 直接运行新版 Setup 覆盖安装；或仅更新引擎：解压 `ximo-agent-v2.1.0.zip`，覆盖安装目录 `resources/backend/`。

### 注意
- 权限模式修改保存后需**重启应用**生效。
- 计划模式与专家选择互斥：选中专家时计划开关自动关闭（专家自带方案阶段）。
- 短回答的流式增量会在几百毫秒内全部到达，观感接近一次性输出，属正常现象。
