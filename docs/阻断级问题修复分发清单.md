### D-1 双版本发布布局（01 ↔ 07）—— 采纳 07 的语义

**裁决：以 07 的「文本指针 + `versions/<version>/` 实体目录」为权威。**

```
<Base>/current   ← 文本文件，内容为当前版本目录路径
<Base>/previous  ← 文本文件
<Base>/versions/<version>/  ← 真正的版本目录

理由：更贴近第 39 章 `install side-by-side → switch current` 的描述，且「回滚 = 改指针」是原子操作。

**裁决：采纳 05 的 `SupervisorAdapter` 方案，不改任一方基础接口签名。**
理由：05 的签名来自第 32.3 节**原文**，改动它会偏离架构；适配器是标准做法，且 05 已实现。

让编译器守住契约。**01 无需改动**。
